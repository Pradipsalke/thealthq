# The ALT HQ website

Website for **The ALT HQ: GCC Beyond The Obvious** by Nilesh Biniwale and Nilesh Kulkarni.

It is a plain static website (HTML and CSS only, no build step), hosted free on GitHub Pages.

## View it locally
Double-click `index.html` to open it in a browser.

## Working with Google Antigravity
1. Unzip this folder and open it in Antigravity (File > Open Folder).
2. Antigravity reads `AGENTS.md` automatically. It contains the rules for this site: brand, structure and what not to change.
3. Ask the agent in plain English, for example:
   - "Add this article to Insights" (attach the PDF or paste the text)
   - "Replace [Contact email] with hello@example.com"
   - "Change the Diamond Publications button to link to ..."
4. Review the summary of changes, then ask the agent to commit and push.

## First-time publishing to GitHub
1. Create a free account at github.com if you do not have one.
2. Ask the Antigravity agent: "Initialise git, create a GitHub repository called the-alt-hq, and push this project to it." Sign in to GitHub yourself when prompted.
3. On GitHub, open the repository, go to Settings > Pages, set Source to "Deploy from a branch", choose `main` and `/ (root)`, and save.
4. The site appears at `https://<your-username>.github.io/the-alt-hq/` within a few minutes. Every later push updates it automatically.
